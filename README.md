# CardioWeekly

A weekly digest of practice-changing cardiology research, published every Sunday.

**Read it:** https://ilias-nikolakopoulos.github.io/cardioweekly/

Each issue covers the past seven days: key takeaways, new guidelines and statements, FDA approvals and Class I recalls, congress late-breakers, and phase 3 trials by topic (coronary and prevention, heart failure, electrophysiology, structural, imaging and vascular). Every journal entry links to a verified DOI or PMID. Past issues are in the [archive](https://ilias-nikolakopoulos.github.io/cardioweekly/archive.html).

CardioWeekly is a summary for clinicians and is not medical advice. Always read the original papers before changing practice.
